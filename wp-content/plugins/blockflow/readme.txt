== Description ==
 
= THE LIGHTWEIGHT GUTENBERG BLOCKS PLUGIN FOR WORDPRESS FULL SITE EDITING =
 
BlockFlow is a fast, no-code block library that brings 25+ professional Gutenberg blocks to the WordPress Site Editor. Build stunning, fully responsive websites with independent desktop, tablet, and mobile controls — no page builder bloat, no coding required.
 
Built for the WordPress Site Editor, BlockFlow gives you complete control over every part of your layout. Adjust spacing, colors, typography, borders, and more from an intuitive inspector. Friendly, real-time controls mean you see every change instantly, so building professional pages feels effortless whether you are a beginner or a pro.
 
Perfect for business websites, landing pages, portfolios, blogs, and WooCommerce stores. Build beautiful designs directly in the WordPress Site Editor.
 
View all features on the [Official Site](https://wpblockflow.com/).

== Installation ==
 
To install BlockFlow, follow these steps:
 
1. Go to Plugins > Add New.
2. Search for "BlockFlow".
3. Install and activate BlockFlow from your Plugins page.
4. Start using blocks — find them in the "BlockFlow" category in the block inserter.
 
== Frequently Asked Questions ==
 
= Does BlockFlow work with any WordPress theme? =
 
Yes. BlockFlow works with any WordPress theme that supports the Gutenberg block editor. It's optimized for Full Site Editing (FSE) block themes.
 
= Is BlockFlow compatible with the WordPress Site Editor? =
 
Yes. All blocks are built using WordPress Block API v3 and work perfectly in the Site Editor and Gutenberg editor.
 
= How do the responsive controls work? =
 
Each block setting that supports responsive design shows device toggle icons. Click the device icon to switch between Desktop, Tablet, and Mobile views and set different values for each breakpoint. Mobile inherits from Tablet, Tablet inherits from Desktop — only override what you need.
 
= Will BlockFlow slow down my website? =
 
No. BlockFlow uses conditional asset loading — CSS and JavaScript only load for blocks actually used on the page. This keeps your site fast and lightweight.
 
= Can I use BlockFlow with other Gutenberg block plugins? =
 
Yes. BlockFlow follows WordPress coding standards and works alongside other Gutenberg block plugins without conflicts.
 
= Where can I find the source code? =
 
Full source code including unminified JavaScript is available at our [GitHub Repository](https://github.com/themeruby/blockflow).
